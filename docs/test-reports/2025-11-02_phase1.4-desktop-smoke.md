## 3) Detailed Test Cases
### T1 — Launch & Tray
- **Steps:** Install MSIX → launch → confirm tray; reopen from tray; verify “Start minimized” pref.  
- **Expected:** Tray present; window toggles; starts minimized when enabled.  
- **Result:** Pass.

### T2 — Soft Lock (UI)
- **Steps:** Create 15m **soft** lock; start Steam/Riot; observe block; cancel lock.  
- **Expected:** Detect/terminate <1s; cancel enabled; countdown accurate (±1s).  
- **Result:** Pass.

### T3 — Hard Lock (UI)
- **Steps:** Create 60m **hard** lock; attempt cancel; try to launch blocked apps.  
- **Expected:** Cancel disabled; enforcement holds; timer accurate.  
- **Result:** Pass.

### T4 — Blocked Apps Management
- **Steps:** Add app → toggle on/off → remove; retry launches after each change.  
- **Expected:** Immediate enforcement without restart.  
- **Result:** Pass.

### T5 — Performance & Stability
- **Steps:** Idle on lock screen 3–5 min; watch Task Manager; scan logs for errors.  
- **Expected:** CPU <1% idle; working set <100MB; no unhandled exceptions.  
- **Result:** Pass.

### T6 — Installer Validation
- **Steps:** Build MSIX → install on clean VM → run T1–T3 → uninstall.  
- **Expected:** No errors; app usable; uninstall clean.  
- **Result:** Pass.
